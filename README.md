# Mother's Day Stories Blog

A beautiful and interactive blog platform dedicated to celebrating mothers through stories, recipes, wisdom, and cherished memories. Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Modern UI/UX**: Clean, responsive design with dark mode support
- **Category Filtering**: Browse content by different categories:
  - Stories (Personal tributes and memories)
  - Recipes (Mom's special dishes)
  - Wisdom (Life lessons from mothers)
  - Traditions (Family customs and celebrations)
  - Letters (Dear Mom messages)
  - Celebrations (Special moments together)
- **Search Functionality**: Find specific articles quickly
- **Pagination**: Easy navigation through articles
- **Hero Slider**: Featured content showcase
- **Responsive Design**: Works seamlessly on all devices
- **Dark Mode**: Comfortable reading in any lighting condition

## 🛠️ Tech Stack

- **Framework**: Next.js 13
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Heroicons, Lucide React
- **State Management**: React Hooks
- **Theming**: next-themes

## 📦 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone <your-repository-url>
   cd mothers-day-blog
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open [http://localhost:3000](http://localhost:3000)** in your browser
